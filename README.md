# Random-Color-Generator
The Random Color Generator is a lightweight web app built with HTML, CSS, and JavaScript. It generates random colors at the click of a button, instantly updating the background and displaying the RGB code. This project is beginner‑friendly and useful for designers or developers looking for quick color inspiration.

## ✨ Features
- Generates random **RGB color codes**
- Displays the color code on screen
- Smooth background transition effect
- Minimal, responsive design
- Beginner‑friendly code structure

---

## 🚀 How to Use
1. Clone or download the repository.  
2. Open `index.html` in your browser.  
3. Click the **Generate Color** button to see a new random color.  
4. Copy the displayed HEX code for your projects.
